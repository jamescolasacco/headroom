What is here: what a portable floating-point build needs, from the release's own lists:
  celt_sources.mk  CELT_SOURCES
  silk_sources.mk  SILK_SOURCES, SILK_SOURCES_FLOAT
  opus_sources.mk  OPUS_SOURCES (only opus.c, opus_decoder.c, opus_encoder.c, extensions.c, repacketizer.c:
                   no multistream / projection), OPUS_SOURCES_FLOAT
plus the headers of celt/, silk/, silk/float/, src/ (less static_modes_fixed.h, static_modes_fixed_arm_ne10.h,
static_modes_float_arm_ne10.h, fixed_debug.h, fixed_generic.h: fixed-point or NE10 only) and include/opus.h,
opus_defines.h, opus_types.h, opus_custom.h.

Not here: dnn/ (deep PLC, DRED, OSCE), CPU-specific code (x86/arm/mips, no run-time CPU detection), fixed point,
tests, demos, build systems. Build settings: host-macos/Package.swift (target COpus): OPUS_BUILD, VAR_ARRAYS,
HAVE_LRINT, HAVE_LRINTF, PACKAGE_VERSION="1.6.1"; plain C, so it builds for arm64 and x86_64 alike.

To update: download the new release, check its SHA-256 against SHA256SUMS.txt, copy the same lists over, and
update this file and PACKAGE_VERSION.
